# Removed tests: U4

- TestRenderInvoiceMigratesLegacyStarterVATRow: it pinned the rewrite of the old starter VAT row into `@@VAT_SUMMARY_ROWS@@`, which is gone. `TestRenderInvoiceRejectsLegacyVATPlaceholders` and `TestUnknownPlaceholderFails` pin that the row's placeholders now fail as unknown.
- TestCreateNewInvoiceFromLastRejectsLegacyArchivedInvoiceKeys: `new --from-last` no longer fails on `line_items`, `invoice.period_label` or `invoice.vat_rate_percent`; it keeps them like any unknown key of an archived invoice. `TestLegacyKeysOfArchivedInvoicesAreUnknownKeys` pins that the new invoice keeps them and fails validation with `unknown key` for each.
- TestEditArchivedInvoiceRejectsLegacyKeys: `archive edit` no longer fails on those keys; it opens the invoice like one with any other unknown key. `TestLegacyKeysOfArchivedInvoicesAreUnknownKeys` pins that the working copy fails validation with `unknown key`.
