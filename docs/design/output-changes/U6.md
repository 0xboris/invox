# Output changes: U6, error wording and adapter errors

## One wording for an output file that exists or is a directory

`cmdutil.OutputError` words `*billing.OutputExistsError` and `*billing.OutputIsDirError` for
every command that writes a file the user names: `new`, `email`, `render` and `build` (`-o`),
and `archive edit` (its working copy). `email.Mailer` now returns these two errors, and the
LaTeX renderer returns `*billing.OutputIsDirError` for `render` and `build`. Exit codes are
unchanged (1).

| Command | Before | Now |
| --- | --- | --- |
| `invox email inv.yaml -o existing.eml` | `error: existing.eml already exists; pass --force or choose another -o path` | `error: existing.eml already exists; pass --force to replace it or choose a different -o/--output path` |
| `invox email inv.yaml -o dir.eml` (a directory) | `error: dir.eml is a directory; choose another -o path` | `error: dir.eml is a directory; choose a different -o/--output path` |
| `invox render inv.yaml -o dir.tex` (a directory) | `error: rename .invox-2546425484 dir.tex: file exists` (a random temporary name) | `error: dir.tex is a directory; choose a different -o/--output path` |
| `invox build -i inv.yaml -o dir.pdf` (a directory) | tectonic ran, then `error: rename .invox-NNN dir.pdf: file exists` (inferred from the code, not run) | `error: dir.pdf is a directory; choose a different -o/--output path`, before tectonic runs |

`new` and `archive edit` already used these words.

Changed files:

- `cmd/invox/testdata/script/email.txtar`: `want-exists.txt` and `want-dir.txt` take the new
  wording.
