# Output changes: U5, command boilerplate

Every command that takes a bounded number of arguments now checks them with
`cmdutil.NoArgs`, `cmdutil.ExactArgs` or `cmdutil.MaximumArgs`, so "unexpected arguments"
lists the arguments past the ones the command takes, worded the same everywhere. Two
commands said it differently:

| Command | Before | Now |
| --- | --- | --- |
| `invox version extra` | `error: unexpected arguments for version: extra` | `error: unexpected arguments: extra` |
| `invox completion zsh extra` | `error: unexpected arguments: zsh extra` | `error: unexpected arguments: extra` |

The second line, `Run 'invox version --help' for usage.` or `Run 'invox completion --help'
for usage.`, and exit 2 are unchanged.

Changed files:

- `cmd/invox/testdata/script/version.txtar`: the `version extra` step expects
  `unexpected arguments: extra`.
- `cmd/invox/testdata/script/completion.txtar`: the `completion zsh extra` step expects
  `unexpected arguments: extra`.

No `docs/cli` or `share/man` page changed.
