# Output changes: U2, drop the legacy config directory

invox no longer reads the old `invoice-tool` config directory next to the invox one. A
support file or `config.yaml` that exists only there is not found: a command that needs the
file fails with the existing usage error (for example `issuer file not found; pass
-u/--issuer, set paths.issuer in config.yaml, or place issuer.yaml at <path>`, exit 2), and a
missing `config.yaml` means the defaults. `init` lost the copy step and its `--force` flag.

What a user sees now:

| Command | Before | Now |
| --- | --- | --- |
| any command that read a file from `invoice-tool` | ran, then `warning: using X from deprecated config directory ...; run 'invox init' to copy it to ...` on stderr | the file is not found; no warning line exists any more |
| `invox config paths` with a file only in `invoice-tool` | that row read `<path>  legacy` | the row reads `none` with an empty path; the `legacy` source is gone |
| `invox init` with files only in `invoice-tool` | asked to copy them, or exited 2 without a terminal | writes the starter files, never asks |
| `invox init --force` | copied the legacy files | exit 2, `error: unknown flag: --force` / `Run 'invox init --help' for usage.` |
| `invox init --forse` | `error: unknown flag: --forse; did you mean --force?` | `error: unknown flag: --forse` |
| `invox config --help` | `preferred: <config.yaml>` and `legacy fallback: <invoice-tool/config.yaml>` | `default: <config.yaml>` |
| `invox init --help` | three Behavior lines on the copy, a Flags block with `--force`, and `$ invox init --force` | none of them |
| `invox config paths --help` | a `legacy` row under Sources | no `legacy` row |
| `invox help environment` | a "Legacy config directory (deprecated)" section, item 4 of "Config file", and "then in the legacy directory" in the support file order; `INVOX_CONFIG_DIR` said the legacy directory is not read | none of them; the `INVOX_CONFIG_DIR` text is rewrapped without that clause |

  `want-legacy-warning.txt` is deleted.

  `preferred:` and `legacy fallback:`; the `init` page loses the copy paragraph, the Flags

- `cmd/invox/testdata/script/help_topics.txtar`: the `environment` page changes as in the
