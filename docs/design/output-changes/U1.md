# Output changes: U1, drop the deprecated command forms

The command forms #106 deprecated and the single-dash long flags no longer work. Each now
exits 2 with a usage error on stderr and nothing on stdout. No `warning: ... is deprecated`
line is printed any more. `docs/cli` and `share/man` are unchanged: the removed forms had no
pages and their flags were hidden.

What a user sees now:

| Command | Exit | stderr |
| --- | --- | --- |
| `invox archive FILE` | 2 | `error: unknown archive subcommand "FILE"` / `Run 'invox archive --help' for usage.` |
| `invox archive` | 0 | none; prints the archive help on stdout, as `customer` and `template` do (was exit 2, missing input) |
| `invox customer config` | 2 | `error: unknown customer subcommand "config"; did you mean "edit"?` / `Run 'invox customer --help' for usage.` |
| `invox send ...`, with or without flags | 2 | `error: unknown subcommand "send"; did you mean "email"?` / `Run 'invox --help' for usage.` |
| `invox nope --to x`, any unknown subcommand before a flag the root lacks | 2 | `error: unknown subcommand "nope"` / `Run 'invox --help' for usage.` (was `error: unknown flag: --to`) |
| `invox new C -s F` | 2 | `error: unknown shorthand flag: -s` / `Run 'invox new --help' for usage.` |
| `invox new C --source F` | 2 | `error: unknown flag: --source; did you mean --force?` / `Run 'invox new --help' for usage.` |
| `invox help customer config`, `invox help send` | 2 | `error: unknown help topic "customer config"` (or `"send"`) / `Run 'invox --help' for usage.` |
| `-names`, `-input`, `-help`, `-version`, `-no-input`, `-output=x.pdf` | 2 | `error: -names is not a flag; use --names` / `Run 'invox <command> --help' for usage.` |
| `-nmaes`, `-bogus` (first letter is no shorthand) | 2 | `error: unknown flag: -nmaes; did you mean --names?` / `Run 'invox <command> --help' for usage.` |

Shorthand groups such as `-ofile.yaml` work as before.

Changed files:

- `cmd/invox/testdata/script/deprecated.txtar`: deleted. Every case pinned a deprecated form.
- `cmd/invox/testdata/script/grammar.txtar`: new cases for each removed form: `archive invoice.yaml`, `customer config`, `send invoice.yaml --to ...`, `new -s`, `new --source`, `help customer config` and `help send`, with the errors above.
- `cmd/invox/testdata/script/archive.txtar`: the missing-input case runs `archive add` (`Run 'invox archive add --help'`), since bare `archive` now prints its help.
- `cmd/invox/testdata/script/help.txtar`: `invox -help` exits 2 with `error: -help is not a flag; use --help` instead of printing the root help with a warning. The `customer config` and `send` help pages and their golden are gone. Bare `invox archive` prints the archive help page.
- `cmd/invox/testdata/script/email.txtar`: `invox send -i invoice.yaml -o draft3.eml` exits 2 with the unknown-subcommand error and writes no draft, instead of drafting one with a warning.
- `cmd/invox/testdata/script/cobra_build_email.txtar`: `build -input x.yaml ...` exits 2 with `error: -input is not a flag; use --input` instead of a warning and a missing-template error. The `send x.yaml --subjct hi` case is gone; `grammar.txtar` covers `send`.
- `cmd/invox/testdata/script/cobra_archive.txtar`: `archive add F.yaml -yes` exits 2 with `error: -yes is not a flag; use --yes` instead of a warning and exit 1.
- `cmd/invox/testdata/script/cobra_customer_edit.txtar`: `customer list -customers other.yaml` exits 2 with `error: -customers is not a flag; use --customers` instead of listing with a warning.
- `cmd/invox/testdata/script/cobra_flags.txtar`: `template list -names` exits 2 with `error: -names is not a flag; use --names` instead of listing with a warning; new case `template list -nmaes` gives `error: unknown flag: -nmaes; did you mean --names?`.
- `cmd/invox/testdata/script/cobra_init.txtar`: `init -force` exits 2 with `error: -force is not a flag; use --force` and writes nothing, instead of running `init --force` with a warning.
- `cmd/invox/testdata/script/cobra_invoice.txtar`: `validate -input ...` exits 2 with `error: -input is not a flag; use --input` instead of a warning and exit 1; new case `build -output=x.pdf` exits 2 with `error: -output is not a flag; use --output` and writes no `utput=x.pdf`.
- `cmd/invox/testdata/script/cobra_root.txtar`: `invox -version` exits 2 with `error: -version is not a flag; use --version` instead of printing the version with a warning.
