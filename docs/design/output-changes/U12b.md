# Output changes: U12b, help routing instead of help goldens

No user-visible output changed. `invox help`, every `--help` page and the generated
`docs/cli` and `share/man` pages are byte-for-byte the same.

Changed files:

- `cmd/invox/testdata/script/help.txtar`: shrunk from 1,448 to 140 lines (N11). It held a
  golden of every help page, which duplicated `docs/cli`. Each of its 24 page goldens
  (`want-root.txt`, `want-customers.txt`, `want-issuer.txt`, `want-defaults.txt`,
  `want-template.txt`, `want-config.txt`, `want-customer.txt`, `want-customer-list.txt`,
  `want-customer-edit.txt`, `want-config-edit.txt`, `want-init.txt`,
  `want-template-list.txt`, `want-completion.txt`, `want-new.txt`, `want-increment.txt`,
  `want-validate.txt`, `want-render.txt`, `want-email.txt`, `want-build.txt`,
  `want-archive.txt`, `want-archive-add.txt`, `want-archive-edit.txt`,
  `want-archive-list.txt`, `want-version.txt`) was byte-identical to the text block of its
  `docs/cli` page once `$HOME` is replaced by the sandbox paths, so the content moved to
  `docs/cli`, which `go run ./internal/docs/gen` regenerates and CI and
  `scripts/verify-target.sh` check for drift. The script now checks routing: `help X`,
  `X --help` and `X -h` print the same page, for the root, a command, two subcommands and
  a group; bare `archive`, `customer` and `template` print their group's page; each help
  topic prints its page and both `defaults` aliases print the `defaults` page; `-help`
  exits 2 (`want-help-single-dash.txt` is kept). Each page is identified by its usage line.
  Every directory a page names from the environment is checked on every OS by a `grep` of
  the scrubbed page, since `docs/cli` shows them only for `$HOME` on Linux. That `help X`
  matches `X --help` for every command is `TestEveryCommandHelpHasAnExample`.
